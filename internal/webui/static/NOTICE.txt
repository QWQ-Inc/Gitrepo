StackEnigma design kit

The visual design (neutral gray scale, type scale, radii, shadows, control
sizes, button / input / tab / table / dialog / sidebar styling) follows
Zeabur's open-source design system:

  https://github.com/zeabur-oss/design-system
  Copyright Zeabur Inc., licensed under the Apache License, Version 2.0
  http://www.apache.org/licenses/LICENSE-2.0

No source files are copied; the CSS re-creates the design tokens and component
styles. The Zeabur name, logo, mark and brand colours are Zeabur's trademarks
and are not part of this kit. The brand colour here (grass green in light mode,
blue in dark mode) is StackEnigma's own; replace it with yours (see README).

Fonts: Geist and Geist Mono (Vercel, SIL Open Font License 1.1) are not
bundled; load them yourself (see README).

Bundled with the Gitrepo console (internal/webui/static):

- stackenigma.css: the design kit above, unmodified.
- fonts/geist-latin-wght-normal.woff2, fonts/geist-mono-latin-wght-normal.woff2:
  Geist and Geist Mono (Latin subset, variable weight) from @fontsource-variable
  5.3.0, SIL Open Font License 1.1 (fonts/OFL-Geist.txt, fonts/OFL-GeistMono.txt).
